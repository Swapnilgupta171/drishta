# Drishta — Visual References

These images establish atmosphere and visual vocabulary. They are inspiration, not screenshots to copy pixel-for-pixel.

## 1. Primary art direction
`drishta_visual_direction.png`

Use this as the main reference for:
- Surreal, dreamlike compositions.
- Art Nouveau botanical ornament and flowing forms.
- Deep green, muted natural tones, antique gold and restrained burgundy.
- Editorial serif typography and asymmetrical layouts.
- The overall sense of an illustrated world.

## 2. Alternate layout and moodboard
`drishta_moodboard_alternate.png`

Use this as a secondary reference for:
- Chapter-based storytelling.
- Ornamental framing and layered illustrations.
- Visual comparison concepts.
- A dark, immersive atmosphere balanced with lighter editorial moments.

## Reference rules
- Extract the visual language; do not reproduce the boards as website sections.
- Keep the style hierarchy: Surrealism first, Art Nouveau second, Paper Cutout as a subtle material influence.
- Do not copy any one composition repeatedly.
- Create a coherent set of original page compositions and assets.
- If a reference conflicts with `design.md` or `animation.md`, follow the written brief.
