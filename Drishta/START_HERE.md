# Start here — Drishta

Build the Drishta website using the project brief files before writing code.

1. Read `design.md` for the visual identity, content and visitor journey.
2. Read `animation.md` for the continuous illustrated story and GSAP implementation rules.
3. Inspect `references/` and use its moodboards as visual direction, not as literal templates.
4. Inspect the existing project and installed GSAP skills; read the relevant skill instructions.
5. Plan briefly, then implement and verify the complete responsive experience.

Preserve the creative intent, use design judgement, and do not invent product capabilities or statistics.
